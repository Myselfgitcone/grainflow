    Before you trust it

    The effect is small. Rating changes explain about 3% of weekly price moves.

    It isn't a trading signal. USDA publishes Monday at 4pm ET. "Next week" here starts at Friday's close, before the report is public.

    Sample size matters. With two seasons the same test wasn't significant. It took nine.

    Today's data quality

    Every record is checked against its contract. Bad ones are quarantined, not dropped.

      Contracts as code

      One YAML per dataset drives producer validation, Spark checks, Iceberg tables, dbt tests and freshness alerts. CI blocks breaking changes.

      A Spark out-of-memory fix

      A 10-year backfill made Iceberg's fanout writer hold about 2,500 open Parquet files. Sorting within partitions switched it to the clustered writer, and memory stayed flat.

      A modeling bug caught

      USDA rates corn in 41 states. Equal weighting let Rhode Island dilute Iowa, so the mart uses the 18 Crop Progress states, with a test guarding it.

      At-least-once, then deduped

      Producer restarts resend data. Bronze keeps every copy with its Kafka offset. Silver keeps one row per natural key.
