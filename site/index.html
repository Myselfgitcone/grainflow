Read this before trusting it

  • Small effect. Rating changes explain only a few percent of weekly price moves (r² ≈ 0.03).
  • Not a trading signal. NASS publishes Monday 4pm ET; "next week" here starts at Friday's close, before the report is public.
  • Sample size matters. On two seasons the same test was not significant; it took nine to get here.

Contracts as code

One YAML per dataset drives producer validation, the schema registry, Spark checks, Iceberg tables, dbt tests and freshness alerts. CI blocks breaking changes.

Fixed a Spark OOM

A 10-year backfill made Iceberg's fanout writer hold ~2,500 open Parquet files. Sorting within partitions switched it to the clustered writer; memory stayed flat.

Caught a modeling bug

NASS rates corn in 41 states. Equal weighting let Rhode Island dilute Iowa, so the mart uses the 18 Crop Progress states, with a test guarding it.

At-least-once, deduped

Producer restarts resend data. Bronze keeps every copy with Kafka offsets; silver keeps one row per natural key.
